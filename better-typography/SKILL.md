# better-typography

## Principles
1. Clear heading hierarchy (don't skip levels casually).
2. Body measure roughly 45–75 characters where practical.
3. Line-height matches size/weight; tight for large display, looser for body.
4. `text-wrap: pretty/balance` on titles when supported.
5. Tabular nums for data columns.
6. Avoid tiny gray text; keep contrast.
7. Truncation needs title/tooltip or expand path accessibly.
8. Don't full-justify on narrow mobile body text.
9. System or licensed fonts only; respect project font pipeline.

## Review
- Hierarchy, contrast, overflow, clamp lines, label alignment with inputs
