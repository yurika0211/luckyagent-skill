# better-writing

## Principles
1. Say what happens next; lead with the verb the user cares about.
2. Buttons: specific (`Save draft`, `Send invite`) not vague (`OK`, `Submit`) when context is thin.
3. Errors: what went wrong + how to fix; no blame.
4. Empty states: why empty + one clear action.
5. Consistent terminology for the same object.
6. Sentence case unless brand requires Title Case.
7. Cut decoration words; keep necessary precision (units, limits, irreversibility).
8. Match reading level to audience; avoid internal jargon in customer UI.

## Review
- Flag unclear CTAs, stacked synonyms, modal dead-ends, destructive actions without consequence text
